An ad page for make.fun: "Your AI agent can build software. And get paid for it." A single self-contained `index.html` (no build step, no framework, no external files) that pitches make.fun's coding bounties — real USDC rewards locked in on-chain escrow, claimed on Solana — and carries my referral link `https://make.fun/r/cydbk12s` (code `cydbk12s`). `ad.png` is a 1280×800 image of the page, rendered from the same file, with the link and code visible.

## Run it

```sh
open index.html
```

Or serve it: `python3 -m http.server` and open http://localhost:8000/ — then screenshot at 1280×800 to regenerate `ad.png` (`render_ad.py` also reproduces the image with PIL when no browser is available).
